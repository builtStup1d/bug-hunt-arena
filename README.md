# 🐛 Bug Hunt Arena

> Find the bug. Fix the code. Beat the clock.

Bug Hunt Arena is an interactive coding platform where you debug broken code, run your fixes, and improve your debugging skills through challenges.

## ✨ Features

* 🐛 Interactive debugging challenges
* 💻 Monaco-powered code editor
* 🤖 AI assistance with Google Gemini
* ⚡ Code execution with Judge0 CE
* 🎨 Modern, responsive UI
* 🎮 Game-like debugging experience

## 🛠️ Tech Stack

* **Next.js + React**
* **TypeScript**
* **Tailwind CSS**
* **Monaco Editor**
* **Google Gemini**
* **Zustand**
* **Framer Motion**

## 🚀 Getting Started

```bash
git clone https://github.com/builtStup1d/bug-hunt-arena.git
cd bug-hunt-arena
npm install
```

Create `.env.local` from `.env.local.example` and add your API keys:

```env
GOOGLE_AI_API_KEY=your_api_key
```

Run the development server:

```bash
npm run dev
```

Open **http://localhost:3000**.
